I build small tools and workflows with AI agents: animation, downloading, subtitles, publishing. Wherever there's repetitive work, I hand it to Claude Code or Codex.

- **eian-riso-broll**: risograph-style info animations for talking-head videos.
- **eian-collage-broll**: editorial halftone paper-collage B-roll workflow.
- **eian-paper-ui-broll**: turns a user ↔ AI conversation into Paper UI motion video.
- **eian-article-art**: chalkboard-style article covers and illustrations; give it a whole article and it picks the spots and draws them.
- **universal-content-intake**: one-link downloader for videos, documents, images and web pages.
- **video-publish-kit**: authorized video URL → Chinese-subtitled video, cover and release notes.
- **x-hdr-video**: posting HDR video on X: the right encoding, tests across 8 accounts, and a script that checks whether X kept the HDR.

Most repos have READMEs in both English and Chinese.
